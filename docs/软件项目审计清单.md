> - 生产级认证：完成 P0 + P1 + P2 全部审计
>
> **版本**：v1.0（2026-08-02，HarPOS 改名 + edition 2024 后建立）

## 二、P0 必做审计（发布前）

### 2.1 工程化审计

**检查项**：
- [ ] `cargo fmt --check --workspace` 通过
- [ ] `cargo clippy --workspace` 0 警告
- [ ] `cargo test --workspace` 全部通过（基线：2035 tests，0 failed）
- [ ] 15 个 example 全部可编译可运行
- [ ] `cargo doc --no-deps` 生成无警告
- [ ] release profile 构建通过（opt-level=3, lto=true）

**通过标准**：所有 gate 100% 通过，0 警告 0 错误。

---

### 2.2 组件模式审计（HarUI 专属 P0）

**目标**：确保每个组件遵循五段式模式，无魔法数字、无 view 副作用。

**检查项**：
- [ ] 每个组件包含：Props struct + State enum + Message enum + view() + handle()
- [ ] Props 使用 builder 模式（`with_*` 方法返回 Self）
- [ ] State enum 有文档注释的状态转换图（如 Dialog: Closed→Opening→Open→Closing→Closed）
- [ ] `view()` 是纯函数（无 IO、无状态写入、无随机性）
- [ ] `handle()` 穷举 Message 变体
- [ ] 样式全部走 `core/src/theme/style_sheets.rs`（组件内无硬编码颜色/间距/圆角）
- [ ] 无魔法字符串协议（Select 的 `"__trigger__"` 等必须有文档说明）
- [ ] 每个组件配套 `*_test.rs`（逻辑）+ `*_view.rs`（渲染）
- [ ] 新组件注册到 `lib.rs` 模块声明

**通过标准**：新组件 5 段式齐全；grep 检查无 `Color::from_rgb` 直接调用在组件内；render test 可稳定断言。

---

### 2.3 敏感信息审计

**检查项**：
- [ ] 无真实密码/API key/token
- [ ] 无真实本机路径（`E:\` 等）
- [ ] 文档示例使用占位符（`<your-xxx>`）
- [ ] `.gitignore` 排除 `.env` / `*.key`
- [ ] Git 历史无凭据泄露

**通过标准**：0 真实生产凭据泄露。

## 三、P1 强烈建议审计（正式版前）

### 3.1 依赖供应链审计

**检查项**：
- [ ] `iced` 0.13.1 来源官方 registry，无 typosquatting
- [ ] `serde` / `chrono` / `proptest` / `criterion` 版本无已知漏洞
- [ ] 传递依赖树可审计（`cargo tree`）

### 3.2 许可证合规审计

**检查项**：
- [ ] HarUI 自身 MIT 许可证与 iced（MIT）兼容
- [ ] **POS 组件（Keypad/Payment/HangOrder/CustomerDisplay/StatusBar）** 商业授权条款明确（open-core 模式：60 通用组件 MIT + POS 组件企业授权）
- [ ] `cargo deny check licenses` 通过

### 3.3 代码覆盖率审计

**检查项**：
- [ ] `har-ui-core` 行覆盖率 ≥ 80%
- [ ] `har-ui-components` 行覆盖率 ≥ 80%
- [ ] POS 组件（Keypad/Payment/HangOrder）覆盖率 ≥ 90%
- [ ] 状态机转换穷举测试全覆盖（所有 State 转换图）
- [ ] 金额精度测试覆盖：进位、大金额、0 金额、负值

**工具**：`cargo llvm-cov` / `cargo tarpaulin`

### 3.4 API 兼容性审计

**检查项**：
- [ ] 组件公开 Props 字段无 breaking change（`cargo semver-checks`）
- [ ] `har-ui-core::Theme` 公开方法稳定
- [ ] CHANGELOG.md 显式标注 breaking change
- [ ] `ButtonKind`（core 侧）与 `ButtonType`（components 侧）映射稳定

### 3.5 主题一致性审计（HarUI 专属 P1）

**检查项**：
- [ ] 6 个设计令牌子系统完整：Color/Typography/Spacing/Radius/Shadow/ZIndex
- [ ] 明暗主题（`element_light()` / `element_dark()`）下所有组件可读
- [ ] `to_iced_theme()` 映射 5 字段 Palette 完整
- [ ] 组件样式函数全部从 `&Theme` 取令牌（无硬编码）
- [ ] 40 个内联 SVG 图标渲染正常

**通过标准**：showcase 示例明暗切换无布局错乱；对比度 ≥ 4.5:1。

### 3.6 性能回归审计

**检查项**：
- [ ] Table 虚拟滚动（threshold=100 行）1000+ 行无卡顿
- [ ] 组件渲染基准（`benches/component_bench.rs`）无回归
- [ ] 启动示例（empty-window）< 2s

**工具**：`criterion`

## 四、P2 中期审计（生产级前）

### 4.1 并发安全审计

**检查项**：
- [ ] 组件无内部可变状态（`Cell`/`RefCell`/`Mutex`），状态全部由应用持有
- [ ] 组件 `Send + Sync`（`cargo check --tests` 的 Send 边界验证）
- [ ] `view()` 引用生命周期正确（`'a` 不逃逸）
- [ ] IME 处理器（`utils/ime.rs`）多线程安全

### 4.2 可维护性审计

**检查项**：
- [ ] 圈复杂度 ≤ 15（组件级）
- [ ] 无循环依赖（core ↔ components 单向依赖）
- [ ] TODO/FIXME 有跟踪
- [ ] 组件文档注释完整（转换图 + 用法示例）
